# Dependencies & Integrations

## Core Flutter Dependencies

- `provider: ^6.1.5+1` — Reactive state injection.
- `flutter_animate: ^4.5.2` — Tokenized micro-interactions.
- `flutter_markdown: ^0.7.7+1` — Rich typography and markdown rendering.
- `shared_preferences: ^2.5.6` — Local persistence for tasks, streaks, and settings.
- `uuid: ^4.6.0` — UUID generation for task entities.
- `enough_mail: ^2.1.7` — Secure IMAP email digest client.
- `http: ^1.2.2` — Resilient Gemini API client.

## Audio & Haptics

- `com.pip.companion/sfx` (Native Kotlin `ToneGenerator` over `STREAM_MUSIC`) — Latency-free hardware robot audio cues.
- `flutter/services.dart` (`HapticFeedback`) — Tactile physical micro-feedback.
- `flutter_tts` / `speech_to_text` — Fallback auxiliary speech pipelines.
